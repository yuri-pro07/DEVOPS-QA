# Trilha Iniciante de Desenvolvimento

## Para quem e a trilha iniciante
A trilha iniciante e indicada para colaboradores com pouca experiencia em programacao, que ainda nao conhecem APIs REST ou banco de dados. Ela forma a base para as trilhas seguintes.

## Cursos da trilha iniciante
Os cursos da trilha iniciante sao Fundamentos de Java, HTTP e APIs REST e SQL Essencial. A ordem recomendada e comecar por Fundamentos de Java, seguir com HTTP e APIs REST e terminar com SQL Essencial.

## Resultado esperado da trilha iniciante
Ao final da trilha iniciante o colaborador escreve programas simples em Java, entende requisicoes HTTP e codigos de status, consome APIs REST e faz consultas SQL com filtros e juncoes.
