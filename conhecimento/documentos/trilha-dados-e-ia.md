# Trilha de Dados e Inteligencia Artificial

## Dados para iniciantes
Quem quer trabalhar com dados e ainda esta no nivel iniciante deve comecar por SQL Essencial antes de qualquer curso de inteligencia artificial.

## Machine Learning
Para quem quer treinar e avaliar modelos de classificacao, medir acuracia e F1 e publicar um servico de inferencia com FastAPI, o curso indicado e Machine Learning para Desenvolvedores. Ele exige nivel avancado ou a conclusao da trilha intermediaria.

## Inteligencia artificial generativa, RAG e agentes
Para quem quer construir recuperacao aumentada por documentos, chatbots com fontes citadas e agentes de IA com ferramentas, o curso indicado e RAG e Agentes de IA com Spring AI. Recomenda-se concluir antes Machine Learning para Desenvolvedores.
